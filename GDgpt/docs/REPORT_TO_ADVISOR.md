## 一、项目概述

### 1.1 核心目标

构建一个**基于知识图谱 (PrimeKG) 增强的多智能体生物医学问答系统**，回答类似以下问题：

- "breast carcinoma 涉及哪些基因和通路？"
- "TP53 基因突变会导致什么疾病？"

### 1.2 技术架构

```
用户问题 → 分诊Agent → KG预取 → 多专家会诊 → 综合输出
                ↓           ↓
           任务分类    PrimeKG (Neo4j)
                        知识图谱检索
```

### 1.3 核心研究问题

| 研究问题      | 说明                                                  |
| ------------- | ----------------------------------------------------- |
| **RQ1** | 知识图谱辅助能否提升 LLM 在生物医学问答任务上的表现？ |
| **RQ2** | 在何种条件下，KG 辅助最为有效？                       |
| **RQ3** | KG 覆盖不足时，系统应如何优雅降级？                   |

## 三、发现的问题

### 3.1 PrimeKG 疾病覆盖有限

| 指标             | 数值   |   评估   |
| ---------------- | ------ | :-------: |
| PrimeKG 疾病总数 | 20 种  | ⚠️ 有限 |
| 测试集疾病匹配率 | 39-50% | ⚠️ 偏低 |
| 基因覆盖率       | 100%   |  ✅ 完全  |
| 通路覆盖率       | 100%   |  ✅ 完全  |

**影响**：Disease-centered 问题中，约 50-60% 的疾病不在 PrimeKG 中，KG 无法提供有效支持。

### 3.2 覆盖率分析结果

| 测试集版本      | 总题数 | KG 可用率 | 用途     |
| --------------- | :----: | :-------: | -------- |
| **Quick** |   30   |   83.3%   | 快速验证 |
| **Full**  |   80   |   86.2%   | 正式实验 |

**按任务类型分析**：

| 任务类型         | Quick 覆盖率 | Full 覆盖率 | 说明                       |
| ---------------- | :----------: | :---------: | -------------------------- |
| pathway-centered |     100%     |    100%    | **最能体现 KG 优势** |
| gene-centered    |     100%     |    100%    | KG 完全支持                |
| disease-centered |     50%     |     39%     | **弱点**，部分无支持 |

### 3.3 当前实验结果

| 指标            |  Full Task KG  |    LLM only    | 说明          |
| --------------- | :-------------: | :-------------: | ------------- |
| Gene F1         | **0.060** |      0.000      | KG 有优势     |
| Pathway F1      | **0.316** |      0.000      | KG 有显著优势 |
| Phenotype F1    |      0.438      | **0.633** | ⚠️ LLM 更好 |
| Bridge Hit Rate | **1.000** |      0.000      | 多跳查询有效  |

**关键发现**：

- ✅ KG 在结构化检索（基因、通路）上有明显优势
- ⚠️ 表型维度 LLM 表现更好（KG 表型节点稀疏）

## 四、解决方案

### 4.1 核心策略：分层评测

不追求"KG 一定优于 LLM"，而是**研究 KG 辅助在何种条件下有效**：

```
测试问题分层：
├── Tier 1: High Coverage (KG 完全支持)
│   ├── Pathway-centered (100% 覆盖) → 预期 KG 显著优于 LLM
│   └── Disease-centered (PrimeKG 中存在的疾病)
│
├── Tier 2: Medium Coverage (KG 部分支持)  
│   └── Gene-centered (56.6% 覆盖) → 预期 KG 有部分帮助
│
└── Tier 3: Low Coverage (KG 无法支持)
    └── Disease-centered (不在 PrimeKG 中) → 分析优雅降级
```

### 4.2 实验设计

| 实验            | 配置           | 目的             | 优先级 |
| --------------- | -------------- | ---------------- | :----: |
| **Exp-0** | Full Task KG   | 完整系统基准     |   P0   |
| **Exp-1** | LLM only       | 纯 LLM baseline  |   P0   |
| **Exp-2** | Single-hop KG  | 仅单跳查询       |   P0   |
| Exp-3           | No KG Prefetch | 验证预取机制价值 |   P1   |
| Exp-4           | No Bridge      | 验证多跳查询价值 |   P1   |

### 4.3 数据优化方案

**方案 A：构建 PrimeKG-Aligned 测试集（推荐）**

```
步骤：
1. 从 PrimeKG 提取 20 种疾病列表
2. 在 Open Targets 中查询这 20 种疾病的基因关联
3. 生成匹配的 disease-centered 问题
4. 扩展至 80 题的平衡测试集
```

**优点**：保证测试集与 KG 高度匹配，充分展示 KG 增强效果

| **条件性有效性分析框架** | 揭示 KG 辅助在何种条件下有效       |
| **多跳 Bridge 查询设计** | Disease→Gene→Pathway 100% 命中率 |

### 5.3 论文叙事

> "Our experiments demonstrate that KG augmentation provides **substantial benefits when knowledge coverage is high** (Pathway F1: +40%), while the system **gracefully degrades to LLM-only performance** when coverage is limited. This reveals that **KG coverage is the critical factor** determining augmentation effectiveness."
