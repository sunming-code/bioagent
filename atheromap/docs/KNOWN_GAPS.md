## 尚未解决的具体代码问题

- 多个亚型 finalize 脚本使用特定 cluster 编号到标签的人工映射；重新聚类后须重新审查。
- R 绘图脚本使用的 `*_celllevel_scores.csv` 导出逻辑未在本包找到，而且输入路径格式与 Python 默认输出不同。
- `summarize_domains.py` 搜索同级 `GSE241346_triptych_*` 目录中的图片；保留多次旧结果时，应记录最终选中的图像来源。
- `annotate_tissue_regions.py` 的区域箭头是推测性示意；没有提供病理专家复核证据。该脚本还使用固定 `/tmp` 图像缓存，图像更新后需核对缓存内容。
- `perform-downstream` 保留原脚本未显式指定的默认参数。安装版本改变可能导致行为差异，复现前应核对原日志 / 版本。
- 只做了交付包的静态与轻量检查，没有测试科学计算依赖的版本兼容性、内存需求、真实运行时长或结果一致性。
